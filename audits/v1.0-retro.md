## Decisions made

*(No formal decisions log existed at v1.0; commit messages are the only record.)*

- **Section numbers are stable identifiers** — never to be renumbered. Cross-references depend on this.
- **Extension model:** each extension extends specific core sections, takes a §N+ section number (16+), and is mapped from §0.5.
- **Audit protocol:** tiered (audit one tier above current), read-only by default.
